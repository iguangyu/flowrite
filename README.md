# FlowWrite · 心流写作终端

> 你写。它在旁边想下一步。
> 不是「人写 / AI 写」两种模式，是同一张纸上的两个人。

一个跑在本地的写作界面。`npx flowwrite` 起服务、开浏览器，剩下的全在键盘上完成。

- **幽灵字**：你停笔一秒多，它在你光标后面续一段淡灰色的字。`Tab` 收下，`Esc` 不要，`Ctrl+→` 只收一句。
  **紧贴光标往后长，不另起一行**，不重复也不覆盖你已经写的字。
  请求一发出，先在同一位置放一串淡淡的乱码占位（90ms 跳一次）；真文字到了，
  按句交给 baffle.js 逐字解出来，占位和真字宽度相近，所以看不出跳变。
  正在流的那半句直接贴上去，不回头重抖。**全程没有任何"正在生成"的文字提示。**
- **文灵**：**它就是你的光标**。你打字的时候，它缩成一根会眨眼的光标；你一停笔，
  它就从光标那儿慢慢长出来——睁眼、飘起来。五种情绪（好奇 / 调皮 / 生气 / 害羞 / 开心），
  眼睛颜色、腮红、嘴角都跟着变。
  **对着光标连按三下空格**，它跳出来给你四个动作（也可以按 `1/2/3/4` 选）：
  1. **接着说**：它接着往下写一段（幽灵字，`Tab` 收下）。
  2. **咬一口**：叼走光标前的一个词，想反悔就点「吐出来」，一字不差还回去。
  3. **换个词**：问模型要一个更贴切的词（"推了推"→"挪了挪"，"陷入了沉思"→"出了神"），
     它先问你「换 / 不换」，你说换才动。
  4. **评一句**：只读你最后一句，给你一句短评。
  另外：点它（或 `Alt+C`）能打开对话面板，本地规则先接、接不住才问模型；
  说「把这句删了」它只**提案**，你不点它不动刀。
  脾气：你把它接的话丢掉（`Esc`），它会生气；你收下（`Tab`），它会开心；闲久了会自己嘀咕一句。
- **三条路**：右下角一个「接下来」按钮，点开是三条走向（用 baffle.js 逐字解码），`Alt+1/2/3` 直接选，不用点开。
- **灵感**：同一个弹窗里还有三张点子卡——道具 / 台词 / 世界观细节 / 反转 / 感官锚点，点一下放到正文末尾等着你改。
- **节奏**：弹窗最下面一行告诉你：这一场在「铺垫 / 升级 / 转折 / 收束」的哪一格、张力多少、**什么变了**、读者现在在等什么，以及一句能落地的诊断（"这场已经攥了两次抹布，别再攥第三次"）。
- **故事档案**：人物、线索、伏笔、时间线，AI 从你写的正文里自己抽，只在总览页出现，不打断你。
- **它不擅自改你的字**。咬一口能吐回来、换个词先问你、删句子先提案 —— 动刀之前一定有一步是你能拒绝的。

## 跑起来

```bash
npx flowwrite
```

或者装到全局：

```bash
npm i -g flowwrite
flow
```

打开后先按任意键过场，然后**第一次要填 API Key**：点右上角「设置」。

| 厂商 | baseURL | 说明 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | 国内直连可用 |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | 国内直连可用 |
| Claude / GPT | 填你的中转地址 | 官方域名国内多数网络不可达 |

Key 只写在本机 `~/.flowwrite/config.json`（权限 0600），不进浏览器存储，也不会出现在任何导出文件里。

命令行参数：

```bash
flow --port 5000        # 换端口
flow --root D:\写作      # 换故事目录
flow --no-open          # 不自动开浏览器
flow --config           # 看配置文件在哪
```

## 键盘

| 键 | 做什么 |
|---|---|
| `Tab` | 收下整段幽灵字 |
| `空格 ×3` | 叫出文灵：接着说 / 咬一口 / 换个词 / 评一句 |
| `1/2/3/4` | 菜单里直接选（菜单亮着时） |
| `Ctrl + →` | 只收下一句 |
| `Esc` | 不要，丢进「备选」（可捡回） |
| `Alt + 1/2/3` | 采用第 N 条走向 |
| `Ctrl + Enter` | 让它多写几段（仍是幽灵字，不直接落字） |
| `Alt + B` | 打开／关闭「接下来」 |
| `Alt + A` | 叫出文灵的四个动作（同三连空格） |
| `Alt + C` | 和文灵说话 |
| `Alt + H` | 让它休息 / 召唤回来 |
| `Alt + K` | 换一批灵感 |
| `Alt + G` | 总览：档案 + 统计 |
| `Alt + M` | 静音 AI（专注时用） |
| `Alt + S` | 设置 |
| `Alt + R` | 重新想三条走向 |

## 界面

单列，**没有侧栏**。正文限宽、居中，其余全是留白；右下角只有一颗「接下来」。

设置里可调：

- **页面尺寸**：默认 `125%`（整页缩放，含顶栏与状态栏）
- 正文字号、行高
- **乱码字符**：幽灵字一套、弹窗一套，各选各的。共 8 种——
  汉字 / 生僻字 / 假名 / 字母 / `0 与 1` / 符号 / 摩斯 / 方块
  - 幽灵字默认「汉字」（混在正文里最不刺眼）
  - 弹窗默认「字母」（一眼就知道是动画，不是正文）
- **占位长度**：等首字时先放几个乱码，默认 10
- 解码速度：幽灵字按毫秒/字，走向按整段时长

## 提示词是从哪来的

不是我自己编的，三条都能追到出处：

- **反 AI 味清单**：`haowjy/creative-writing-skills`（Apache-2.0）的 `writing-principles`
  与 `resources/antipatterns.md`。落进提示词的是它列的几条：命名情绪、否定对偶
  （"不是愤怒，是更安静的东西"）、段尾总结、同一套身体反应、破折号。
  另外用上了它的「读者回报通道」和「角色只知道他经历过的事」。
- **场次四问**：同仓库 `story-architecture/chapter-and-scene.md` ——
  这一场**什么变了**、谁的场、读者学到什么、跟主线什么关系。节奏面板就是按这个问的。
- **关键词语料注入**：NovelAI Lorebook 的 key-activated context。
  不再把整本圣经塞进上下文，只挑「最近 1500 字里真的出现过名字」的条目，主角和世界规则常驻。
  写长了之后这一步决定了上下文是「相关」还是「又长又无关」。
- **点子卡的形式**：同仓库 `story-planning/brainstorming.md` ——
  给 2-3 个彼此不同、具体到能评估的选项，**不给推荐**（收敛是作者的事）。

## 它在背后怎么工作

**双上下文预算**——不是把所有东西都塞进去。

- 续写（高频）：最近约 2400 字 ＋ 档案摘要 ＋ 当前场 ＋ 当前方向。目标首字 1.4 秒。
- 想走向 / 理档案（低频）：全文 ＋ 完整档案。慢一点没关系，反正不挡你打字。

**三个模型角色**可以分开配：写正文的、想走向的、理档案的。默认都用 `deepseek-flash`（实测首字 1.4s）。
`deepseek-v4-pro` 会把 token 全烧在推理上、正文返回空，不建议用来写——设置页里有标注。

**触发节奏**：停笔 0.65 秒且这次新增 ≥ 4 字就出手；走向每写 180 字重算一次，过期会先压暗再自动换新。

**它不出手的时候会告诉你为什么**（状态栏）：`光标不在文末，它只在末尾接话` /
`再写 2 个字就接` / `AI 已静音`。这几条提示有优先级，不会被别的状态盖掉。

**不做的事**：不做向量库，不做集/场/景 实体管理，不做自动改写，不做云同步。短剧体量（1–3 万字）用不着这些，加了只会变慢变复杂。

## 数据在哪

一个故事一个目录，全是纯文本，可以直接 `git init` 版本化：

```
~/FlowWrite/<故事名>/
  story.json       标题、一句话、体裁、风格样张
  manuscript.md    正文（唯一真相）
  bible.json       人物 / 世界观 / 线索 / 伏笔 / 时间线
  beats.jsonl      你选过和丢过的走向
  .flowwrite/
    snapshots/     每涨 400 字一个快照，留最近 50 个
    state.json     光标、侧栏状态
```

场标题就写在正文里，一行即可，未来接分镜时按这行切：

```
场1 · 内景 周记修车铺 · 夜
```

## 已知边界

- 幽灵字只出现在**文末**。光标不在末尾时它不会开口——这是刻意的，避免在你回头改稿时突然冒字。
- 只支持 OpenAI 兼容协议（`/chat/completions`）。绝大多数中转都满足。
- 单机、单人。没有账号，也就没有同步。
- Windows / macOS / Linux 都行，需要 Node 18+。
